Words used in this report

FASTQ file
Raw reads straight from the sequencer. Each read has its DNA letters plus a quality score for every letter. This is the normal starting point for analysis.
Depth (coverage)
How many times, on average, each position of your target was read. Calculated as total sequenced bases ÷ target size. Each position needs to be read many times to tell real mutations from sequencing errors. Rough guide: plasmid assembly ≥ 30× (Illumina) or ≥ 20× (Nanopore); variant calling in amplicons ≥ 100×.
Mean quality (Phred score)
The sequencer's confidence in each letter. Q20 = 1 error in 100 letters, Q30 = 1 in 1,000. Illumina data is usually Q30+. Nanopore is typically Q10–Q20 per read, which is fine because many reads are combined.
Paired-end reads (R1 / R2)
Illumina read each DNA fragment from both ends, giving two files that belong together. Pairs carry extra information about distance between reads, which makes assembly and alignment more reliable. Both files must always be used together.
De novo assembly
Building the sequence from the reads alone, like a puzzle without the box picture. Finds insertions, deletions, rearrangements and unexpected sequence that a reference would hide. Recommended for plasmids.
Circular contig
The assembler found that the sequence's end joins its start, as expected for a plasmid. A single circular contig of the expected size is the ideal result.
Comparing an assembly to a reference
Lining up your assembled plasmid with the plasmid map you expected. Shows every difference and which feature (gene, promoter, marker) it falls in.
Subsampling
Using only part of the reads. Plasmids are tiny, so runs often give 1000×+ depth. Too much depth can confuse assemblers; ~100–150× is plenty.
Quality trimming
Removing adapter sequences and low-quality ends from reads. Prevents sequencing artefacts from appearing as fake mutations.
Variant
A position where your sample differs from the reference. SNP = one letter changed; insertion/deletion (indel) = letters added or removed.
Frameshift
An insertion or deletion whose length is not a multiple of 3 inside a protein-coding gene. Changes every amino acid after it and usually destroys the protein.
GenBank / SnapGene file
A sequence with its features annotated (genes, promoters, resistance markers, primers). Best kind of reference: SeqGuide can tell you *which feature* a mutation falls in and what it does to the protein.
